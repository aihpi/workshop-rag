# RAG workshop materials

Teaching material of the HPI AI Service Centre for the workshop series on Retrieval-Augmented Generation (RAG II: chunking, embeddings, retrieval, document types; RAG III: evaluation with RAGAS).

All learning material lives in [`notebooks/`](notebooks/README.md), which explains the setup (Python environment, Qdrant via `docker compose up -d`, API access) and lists the notebooks.
